# حور تلعب وتتعلم

لعبة تعليمية عربية للأطفال تجمع بين اللعب السريع، الأسئلة التعليمية، خريطة المراحل، روضة القرآن، وبطاقات المراجعة.

## آخر تحسينات تجربة الاستخدام

- تنقل سفلي ثابت ومناسب للهاتف.
- أزرار لمس كبيرة وواضحة للعب على الشاشات الصغيرة.
- دعم مناطق الأمان في الأجهزة ذات النوتش.
- حفظ آخر قسم فتحه اللاعب.
- تنبيه واضح عند انقطاع الاتصال، مع استمرار الحفظ المحلي.
- تبسيط العناوين وتقليل الأيقونات والزخارف المكررة.
- لوحة ألوان أهدأ وتقليل مؤثرات الإضاءة.
- حماية بيانات النسخ الاحتياطي المستوردة ومنع إدخال HTML في لوحة المتصدرين.
- إزالة تسجيل Google ومزامنة Firebase الوهمية من النسخة المحلية.
- إعدادات Android TWA وفحص إصدار قبل النشر.

## التشغيل المحلي

```bash
corepack enable
pnpm install
pnpm test
pnpm run build
pnpm run verify:release
```

## إصدار Android

ملفات إصدار Android موجودة داخل `android/`. يجب إنشاء مفتاح Release خارج المستودع، ثم إعداد `assetlinks.json` على النطاق الإنتاجي، وبناء ملف AAB موقّع قبل الرفع إلى Google Play.

لا يحتوي هذا المستودع على ملف APK جاهز حتى لا يتم توزيع نسخة قديمة بالخطأ. راجع [دليل إصدار Android](android/README.md).

## ملاحظة الخصوصية والأطفال

اللعبة موجّهة للأطفال، لذلك يجب إكمال سياسة الخصوصية، نموذج Data Safety، تصنيف المحتوى، ومتطلبات Google Play Families قبل النشر العام. راجع متطلبات Google Play الحالية قبل إرسال الإصدار.
